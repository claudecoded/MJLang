# MJLang 🕺✨

**MJLang** is an esolang (esoteric programming language) based entirely on the songs, dance moves, and iconic vocal ad-libs of the King of Pop, Michael Jackson. Inspired by ArnoldC, it replaces boring traditional syntax with keywords that will make your terminal do a flawless Moonwalk.

Are you ready to find out if your code is a *Smooth Criminal*?

---

## Syntax Guide (MJLang vs C/Python)

| MJLang Command | Meaning / Equivalent | Original Context |
| :--- | :--- | :--- |
| `OW!` | Start of the program (`main`) | High-pitched vocal ad-lib |
| `HEE-HEE!` | End of the program | Iconic signature laugh |
| `SHAMONE` | Declare Variable / Begin Assignment | From the song *Bad* |
| `BILLIE JEAN` | Assign Value / Initializer | *Billie Jean* |
| `AOW` | End of statement | Transition grunt |
| `JAM` | Print to console (`printf` / `print`) | From the song *Jam* |
| `WHO'S BAD` | Conditional Statement (`if`) | *Bad* |
| `BEAT IT` | Conditional Alternative (`else`) | *Beat It* |
| `YOU'VE BEEN HIT BY` | End of Conditional (`endif`) | *Smooth Criminal* |
| `MOONWALK` | Loop Statement (`while`) | Signature dance move |
| `DON'T STOP 'TIL YOU GET ENOUGH` | End of Loop (`endwhile`) | *Don't Stop 'Til You Get Enough* |
| `THRILLER` | Addition Operator (`+`) | *Thriller* |
| `BAD` | Subtraction Operator (`-`) | *Bad* |
| `BLACK OR WHITE` | Equality Operator (`==`) | *Black or White* |

## Code Examples

### 1. Hello World (Hello Annie)
```mjlang
OW!
JAM "Annie, are you ok?"
HEE-HEE!
```

### 2. A Simple Loop Counter (Counts to 3)
```mjlang
OW!
SHAMONE counter BILLIE JEAN 0 AOW
SHAMONE limit BILLIE JEAN 3 AOW

MOONWALK counter BLACK OR WHITE limit
    JAM counter
    SHAMONE counter BILLIE JEAN counter THRILLER 1 AOW
DON'T STOP 'TIL YOU GET ENOUGH

HEE-HEE!
```
